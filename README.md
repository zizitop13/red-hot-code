# Red Hot Code

An IntelliJ IDEA plugin that reveals defect hotspots from repository history by correlating Git changes with Jira bug issues.

The plugin will surface file- and class-level risk using colors, defect counts, and drill-down links to the issues that contributed to the score.

## Status

Early development. Work is organized as sequential GitHub issues titled `Phase ...`; each phase is implemented through its own pull request.
